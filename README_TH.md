# T14 Machine Log — คู่มือติดตั้งและใช้งาน

โปรแกรมบันทึกปัญหา / การปรับปรุงเครื่องจักรของ Line T14
ทำงานบนเครื่องนี้เท่านั้น (Offline) — ข้อมูลไม่ถูกส่งออกไปภายนอก

## 1. ติดตั้ง (ครั้งแรก)

1. คลายไฟล์ `T14-Machine-Log-v1.10.3-win64.zip` (คลิกขวา → **Extract All…**)
   ไปไว้ที่ที่ต้องการ เช่น `D:\T14-Machine-Log`
   - แนะนำให้วางใน **Drive D:** หรือโฟลเดอร์ที่ไม่ใช่ `C:\Program Files` (ต้องเขียนไฟล์ได้)
   - **ต้องคลายไฟล์ออกมาก่อน** ห้ามเปิดจากในไฟล์ .zip โดยตรง
2. ดับเบิลคลิก **`Start.bat`**
3. ครั้งแรก Windows / Antivirus อาจถาม → เลือก **More info → Run anyway** / **Allow**
   - ถ้า Windows Firewall ถาม: เลือก **ยกเลิก (Cancel)** ได้ — โปรแกรมใช้งานเฉพาะในเครื่องนี้ ไม่ต้องเปิด Network
4. Browser จะเปิดหน้า `http://localhost:8014` ให้อัตโนมัติ

> สร้าง Shortcut: คลิกขวา `Start.bat` → **Send to → Desktop (create shortcut)**

## 2. การเปิด / ปิดโปรแกรม

## 3. การใช้งาน

### 3.1 บันทึกงาน
**แถบด้านบน:** เลือกวันที่ (◀ ▶ / วันนี้) → กรอก **เป้าหมาย** + **ผลิตได้** → ผลต่างคำนวณให้ → **บันทึกยอดผลิต**
- **☐ วันหยุด**: ติ๊กได้ทุกวันที่ต้องการ → เป้าหมาย/ผลิตได้ไม่บังคับ และไม่เติมเป้าหมายเริ่มต้นให้ (ถ้าวันหยุดมีการผลิตจริง กรอกครบสองค่าแล้วยังนับในยอดรวมตามปกติ) — บันทึกปัญหา/การปรับปรุงในวันหยุดได้ตามปกติ
ด้านขวาแสดง "วันนี้ N รายการ · X ชม." (บรรทัดล่าง = Stop Line / Monday Cleaning ที่ไม่นับ) และปุ่ม **📋 ดู / แก้ไขรายการ** (เปิดหน้าต่างรายการของวัน → แก้ไข / ลบ / เปิดไฟล์แนบ)
- **↪ ย้ายวัน** (v1.10 — กรอกผิดวัน): ย้ายยอดผลิตของวันนั้นไปวันที่ถูก + ติ๊ก "ย้ายรายการปัญหา / การปรับปรุงไปด้วย" (ค่าเริ่มต้น = ติ๊ก; Stop Line เลื่อนวันที่สิ้นสุดเท่ากัน)
  - **ไม่เขียนทับ**: ถ้าวันที่ปลายทางมียอดผลิตอยู่แล้ว จะย้ายไม่ได้ (แก้ไข/ลบยอดผลิตวันนั้นก่อน)

**กรอบ ⚠ ปัญหาเครื่องจักร (สีส้ม)** และ **กรอบ 🔧 การปรับปรุง (สีน้ำเงิน)** — กรอกและบันทึกแยกกันได้
- เวลาเริ่ม / สิ้นสุด พิมพ์ `7`, `7.00`, `13.30`, `24.00` ได้ → **ชั่วโมง** = (สิ้นสุด − เริ่ม) + 1 เช่น 7.00–8.00 = 2, 19.00–3.00 = 9
- **กะ** จากเวลาเริ่ม: เช้า 06.00–17.59 / ดึก 18.00–05.59
- Size / เครื่องจักร / ผู้รับผิดชอบ: พิมพ์เองหรือกด ▼ เลือก — รายการเครื่องจักร = เครื่องจริง 13 เครื่องตามลำดับ (v1.9) แก้/ลบ/เลื่อนลำดับได้ที่หน้าตั้งค่า
- ปัญหา / การแก้ไข / งานที่ปรับปรุง / รายละเอียด: **พิมพ์อิสระ**
- กรอบปัญหา**ไม่มี** กำหนดเสร็จ / ผู้รับผิดชอบ / สถานะ
- **📦 คิดจากยอดผลิต** (ในกรอบปัญหา — เครื่องเสียแต่ยังมีงานออกไม่เต็ม): กรอก **เวลาเริ่ม – สิ้นสุด** (v1.10) + **เป้าผลิต/ชม.** (ค่าค้างไว้ใช้ครั้งต่อไป) → ช่อง **ผลิตได้จริง** ขึ้นให้ 1 ช่องต่อ 1 ชั่วโมง พร้อมป้ายเวลา (9.00–10.00 = ช่อง 09.00 และ 10.00; ช่องว่างไม่นับ) — **กะคิดจากเวลาเริ่ม**
  - ชั่วโมงสูญเสีย = (เป้า − ผลิตได้จริง) ÷ เป้า × จำนวนชั่วโมงที่กรอก เช่น เป้า 7,000 ผลิตได้ 3,500 → **0.5 ชม.**, เป้า 6,000 ผลิตได้ 4,500 / 3,000 / 5,400 → **0.85 ชม. (51 นาที)**; ผลิตเกินเป้าได้ (ไม่ติดลบ)
  - **ช่วงเวลาบอกว่าเกิดช่วงไหนเท่านั้น — ตัวเลขชั่วโมงยังมาจากยอดผลิต** (ไม่ใช่สูตรเวลา)
  - รายงานแสดงเวลาเริ่ม / สิ้นสุดตามจริง + ยอดผลิตแบบจาง ๆ ใต้ข้อความปัญหา; รายการเก่า (v1.9) ที่ไม่มีเวลาแสดงยอดผลิตในช่องเวลาเหมือนเดิม — ถ้าแก้ไขรายการเก่า ต้องกรอกเวลาก่อนบันทึก
  - ช่องเวลาใช้ร่วมกับโหมดปัญหาเครื่องจักร: สลับโหมดแล้วเวลาที่พิมพ์ไว้ไม่หาย
- **⏸ Stop Line** (ในกรอบปัญหา): ระบุ **วันที่เริ่ม - วันที่สิ้นสุด** → ชั่วโมงขึ้นให้ = จำนวนวัน × 24 (แก้ตัวเลขเองได้ เช่น หยุด 2 ชม.) — ไม่มีเวลา/กะ/Size, เครื่องจักรไม่บังคับ
  - Stop Line เป็น**ข้อมูลบันทึกอย่างเดียว ไม่นับชั่วโมงในกราฟหรือชั่วโมงรวมใด ๆ**
- **🧽 Monday Cleaning** (v1.10 ในกรอบปัญหา — หยุดทำความสะอาดตามแผนประจำสัปดาห์ **ไม่ใช่ปัญหาและไม่ใช่งานปรับปรุง**): กรอก **เวลาเริ่ม – สิ้นสุด** (ชั่วโมง/กะคิดให้เหมือนเดิม) — เครื่องจักร**ไม่บังคับ** (ว่าง = ทั้ง Line), รายละเอียดไม่บังคับ (ว่าง = "Monday Cleaning"), แนบรูปได้, ไม่มี Size
  - **ลงรายงาน** (ป้ายสีเขียวน้ำทะเล, ชั่วโมงสีจาง + สรุปแยกท้ายรายงาน) แต่**ไม่ลงกราฟ ไม่นับในชั่วโมงรวม / ชั่วโมงสูญเสีย** — เหมือน Stop Line
  - ตามหลัก OEE / ISO 22400: การหยุดตามแผน (Planned Downtime) ไม่นับเป็นเวลาสูญเสีย
  - รายการเก่าที่เคยบันทึกเป็นเครื่องจักร "MONDAY Cleaning" ถูกแปลงเป็น Monday Cleaning ให้อัตโนมัติตอนอัปเกรด (มี Backup "ก่อนอัปเกรด")
- **กรอบการปรับปรุง**: กำหนดเสร็จ, ผู้รับผิดชอบ, **สถานะ** = รอดำเนินการ (ค่าเริ่มต้น) / ระหว่างดำเนินการ / เสร็จแล้ว
- **📎 แนบเอกสาร**: รูปภาพ / PDF / Excel / Word สูงสุด 5 ไฟล์ต่อรายการ ไฟล์ละไม่เกิน 20 MB (อัปโหลดเมื่อกดบันทึก) — ตอนแก้ไขกด ✕ ที่ไฟล์เพื่อลบ (↺ ยกเลิก)
- แก้ไขรายการ: ปุ่ม **ดู / แก้ไขรายการ** → **แก้ไข** → ข้อมูลไปอยู่ในกรอบที่ตรงประเภท → บันทึกการแก้ไข
- **แก้วันที่ของรายการ** (v1.10 — กรอกผิดวัน): ระหว่างแก้ไขมีช่อง **วันที่ของรายการ** บนหัวกรอบ → เปลี่ยนแล้วกดบันทึกการแก้ไข (ข้อความยืนยันมีปุ่ม "ไปที่วันที่ …")
  - หรือกด ◀ ▶ / เลือกวันที่ด้านบนระหว่างแก้ไข → โปรแกรมถาม **ย้ายรายการนี้ไปวันที่ …** / ทิ้งการแก้ไข / ยกเลิก (เดิมฟอร์มถูกล้างโดยไม่ถาม — รายการยังอยู่ที่วันเดิม)
- กะดึกหลังเที่ยงคืน: เลือกวันที่เองตามที่ใช้ในฟอร์มกระดาษ

### 3.2 รายงาน
เลือกช่วงวันที่ / **ประเภท** (ปัญหา, ปัญหา+Stop Line+Cleaning, การปรับปรุง, Stop Line, Monday Cleaning, ทั้งหมด) / เครื่องจักร / Size / **กะ** / **สถานะ** (งานปรับปรุง) → **แสดงรายงาน** → **พิมพ์ / บันทึก PDF**
- ประเภทที่เป็นปัญหา / Stop Line: ไม่มีคอลัมน์ กำหนดเสร็จ / ผู้รับผิดชอบ / สถานะ
- สถานะมีตัวเลือก **รอดำเนินการ / ระหว่างดำเนินการ (ยังไม่เกินกำหนด)** ตรงกับแท่งในกราฟงานปรับปรุง
- การปรับปรุง / ทั้งหมด: มีคอลัมน์ กำหนดเสร็จ / ผู้รับผิดชอบ / สถานะ
- ชั่วโมงรวมไม่นับ Stop Line / Monday Cleaning (แสดงแยกท้ายรายงาน)
- แสดง**ทุกวัน**ในช่วงที่เลือก: วันที่ยังไม่บันทึกเป้าหมาย/ยอดผลิต = **"—" พื้นเหลือง** (ชี้เมาส์เพื่อดูว่าขาดอะไร), วันหยุด = **"วันหยุด" สีเทา**, วันที่ยังไม่ถึงไม่ถือว่าขาด
- แถวรวม 2 แถว: **รวม** = ผลบวกของคอลัมน์ / **เฉพาะ N วันที่มีครบ** = เฉพาะวันที่มีทั้งเป้าและยอดผลิต (ตัวเลขเดียวกับ Dashboard + % บรรลุเป้า)
- **📥 Excel**: ส่งออกรายงานที่แสดงอยู่ (ตัวกรองเดียวกัน) เป็นไฟล์ .xlsx 3 Sheet — รายการ (1 แถวต่อรายการ กรอง/Pivot ได้) / ยอดผลิตรายวัน (มีคอลัมน์หมายเหตุ: วันหยุด / ยังไม่บันทึก...) / สรุป
- **พิมพ์ตามตัวกรอง** (v1.10.1): ถ้าเลือกตัวกรองใด ๆ (ประเภท / เครื่องจักร / Size / กะ / สถานะ) ตอนพิมพ์จะแสดง**เฉพาะวันที่มีรายการตรงตัวกรอง** (บนจอยังเห็นทุกวัน) — ไม่เลือกตัวกรอง (ประเภท "ทั้งหมด") พิมพ์ครบทุกวันเหมือนเดิม
- **เลือกประเภทแล้วพิมพ์เฉพาะประเภทนั้น** (v1.10.2): เมื่อเลือกประเภทอื่นที่ไม่ใช่ "ทั้งหมด" ตอนพิมพ์จะไม่มีคอลัมน์ เป้าหมาย / ผลิตได้ / ผลต่าง, แถวสรุปยอดผลิต และหมายเหตุวันหยุด/ขาดข้อมูล (บนจอและ Excel ยังครบ) — เลือก "ทั้งหมด" พิมพ์ครบเหมือนเดิม
(ในหน้าต่างพิมพ์เลือก **Layout: Landscape**, ติ๊ก **Background graphics** เพื่อให้มีสี)

### 3.3 Dashboard
- กล่องตัวเลข 10 กล่อง: เป้าหมายรวม · ผลิตได้รวม · ผลต่างรวม · % บรรลุเป้า · ยอดผลิตเฉลี่ย/วัน · ชั่วโมงสูญเสียรวม (เฉพาะปัญหาเครื่องจักร) · เครื่องจักรที่ใช้เวลามากที่สุด · ปัญหา/การปรับปรุง · งานที่ปรับปรุงแล้วเสร็จ · งานปรับปรุงที่ยังไม่เสร็จ
- **สีแถบหน้ากล่อง**: เขียว = ดี (ถึงเป้า / ดีขึ้น), ส้ม = ไม่ดี (ต่ำกว่าเป้า / แย่ลง), ฟ้า = ค่าตั้ง
- **เปรียบเทียบกับ**: ช่วงก่อนหน้า (ค่าเริ่มต้น) / ช่วงเดียวกันปีก่อน / เลือกช่วงเอง / ไม่เปรียบเทียบ → ใต้ตัวเลขแสดง ▲▼ และค่าของช่วงที่เทียบ
  - ช่วงที่เทียบไม่มีข้อมูล → แสดง "ไม่มีข้อมูล" (ไม่เทียบกับ 0)
- กล่องเป้าหมายรวมแสดง "คิดจาก N วัน · วันหยุด N วัน · ขาดข้อมูล N วัน" (ขาดข้อมูล = วันที่ผ่านมาแล้วที่ยังไม่บันทึกเป้าหมาย/ยอดผลิต)
- **คลิกที่กล่องตัวเลข** (v1.9): กล่องยอดผลิต → หน้ารายงานช่วงเดียวกัน, กล่องอื่น → หน้าต่างรายการ (จำนวนเท่ากับตัวเลขในกล่อง)
- **กราฟแท่งตั้ง 4 กราฟ**: แถวบน = **ตามเครื่องจักร** (เต็มความกว้าง), แถวล่าง = **ตาม Size (⌀)** · **ตามกะ** · **งานปรับปรุง**
  - เครื่องจักร: **ทุกเครื่องตามลำดับในหน้าตั้งค่า** (แม้ไม่มีข้อมูล) เลือกเรียง **ตามเครื่อง / ชม. / ครั้ง**
  - เครื่องจักร / Size: ประเภท **ทั้งหมด** = แท่ง **ปัญหา (ส้ม)** กับ **การปรับปรุง (น้ำเงิน)** วางคู่กัน; Size / กะ แต่ละหมวดไล่โทนในสีเดียว (กะดึก = เข้ม, กะเช้า = อ่อน)
  - บนหัวแท่ง: **ชม. (ครั้ง)** และ **%** (ตัวเล็กกว่า ไม่หนา) — % เทียบกับผลรวมของประเภทนั้นเอง; ไม่มีข้อมูล = "0" สีเทา
  - **ตามกะ**: เฉพาะปัญหาเสมอ
  - **งานปรับปรุง**: เสร็จแล้ว (เขียว) / รอดำเนินการ / ระหว่างดำเนินการ / เกินกำหนด (ส้มอ่อน → เข้ม) — ไม่นับซ้อนกัน **รวม 4 แท่ง = 100%** (รอ/ระหว่าง = ที่ยังไม่เกินกำหนด)
  - กล่อง **งานที่ปรับปรุงแล้วเสร็จ / งานปรับปรุงที่ยังไม่เสร็จ** ใช้ตัวเลขเดียวกับกราฟนี้
- **Stop Line / Monday Cleaning ไม่อยู่ในกราฟและชั่วโมงรวม** (จำนวนครั้งแสดงในกล่อง "ปัญหา / การปรับปรุง")
- **แสดง %: เปิด | ปิด** (แถบตัวกรอง — โปรแกรมจำค่าที่เลือก)
- **คลิกที่แท่งกราฟ** (แท่งสีไหน = เฉพาะประเภทนั้น) → หน้าต่างรายการ → **เปิดในหน้ารายงาน** เพื่อพิมพ์
- **พิมพ์ / PDF**: A4 แนวนอน 1 หน้า (ในหน้าต่างพิมพ์ เลือก Layout: Landscape, ติ๊ก Background graphics) — กราฟเครื่องจักรเกิน 15 เครื่องพิมพ์ 14 รายการแรก + "อื่น ๆ"

### 3.4 ตั้งค่า
ชื่อ Line, เป้าหมายเริ่มต้นต่อวัน, เวลาเริ่มกะ, รายการตัวเลือก (Master) — **▲▼ เลื่อนลำดับ** (ลำดับเครื่องจักร = ลำดับในช่องเลือกและกราฟ), Backup / Restore

## 4. ข้อมูลและการสำรองข้อมูล (สำคัญ)

| สิ่งที่เก็บ | ตำแหน่ง |
|---|---|
| ข้อมูลทั้งหมด | `data\t14.db` |
| ไฟล์แนบ | `data\attachments\` |
| ไฟล์ Backup | `backups\T14_backup_YYYYMMDD_HHMMSS_<ประเภท>.zip` |

- **Backup อัตโนมัติ** วันละ 1 ครั้งเมื่อเปิดโปรแกรม เก็บ 30 ชุดล่าสุด (ชุดที่เก่ากว่าลบอัตโนมัติ)
- Backup **รวมไฟล์แนบ** ด้วย → ขนาด Backup เพิ่มตามไฟล์แนบ (30 ชุด × ขนาดไฟล์แนบทั้งหมด) ตรวจพื้นที่ดิสก์เป็นระยะ
- อัปเกรดเวอร์ชันที่เปลี่ยนโครงสร้างข้อมูล: ระบบสร้าง Backup "ก่อนอัปเกรด" ให้อัตโนมัติก่อนแปลงข้อมูล
- **Backup เอง**: หน้าตั้งค่า → **Backup ตอนนี้** (ไม่ถูกลบอัตโนมัติ)
- **Restore**: หน้าตั้งค่า → กด Restore ที่ไฟล์ที่ต้องการ หรือเลือกไฟล์ .zip
  ระบบจะ Backup ข้อมูลปัจจุบัน ("ก่อน Restore") ให้อัตโนมัติก่อนเสมอ → ถ้า Restore ผิดชุด สามารถ Restore ชุด "ก่อน Restore" กลับได้
- ⚠ Backup ทั้งหมดอยู่ในเครื่องเดียวกัน — **ถ้าฮาร์ดดิสก์เสีย Backup จะหายด้วย**
  แนะนำให้คัดลอกโฟลเดอร์ `backups` ไปเก็บใน USB / Drive อื่นอย่างน้อยสัปดาห์ละครั้ง

### ย้ายเครื่อง / อัปเดตเวอร์ชัน
- ย้ายเครื่อง: ปิดโปรแกรม → คัดลอกโฟลเดอร์ทั้งหมดไปเครื่องใหม่ → เปิด `Start.bat`
- อัปเดตเวอร์ชัน: ปิดโปรแกรม → คลายเวอร์ชันใหม่ → คัดลอกโฟลเดอร์ `data` และ `backups` จากเวอร์ชันเดิมมาวางทับ → เปิด `Start.bat` (ระบบ Backup "ก่อนอัปเกรด" แล้วแปลงข้อมูลเดิมให้อัตโนมัติ — ข้อมูลในช่องที่ไม่ใช้แล้วยังเก็บไว้ในฐานข้อมูล)

## 5. แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| หน้าเว็บแจ้ง "ติดต่อโปรแกรมไม่ได้" | หน้าต่างสีดำถูกปิด → เปิด `Start.bat` ใหม่ |
| หน้าต่างสีดำแจ้ง "Port 8014 ถูกโปรแกรมอื่นใช้งานอยู่" | ปิดโปรแกรมที่ใช้ Port นั้น หรือแจ้งผู้ดูแลเพื่อเปลี่ยน Port |
| `python\python.exe not found` | ไม่ได้คลายไฟล์ zip ทั้งหมด → Extract All ใหม่ |
| Antivirus บล็อก | ให้ IT เพิ่มโฟลเดอร์โปรแกรมเป็นข้อยกเว้น (Whitelist) |
| ข้อมูลผิด / ลบผิด | หน้าตั้งค่า → Restore จาก Backup ล่าสุดก่อนเกิดปัญหา |
